## Описание проекта

**Personal Diary** — это веб-приложение для ведения личного дневника, созданное на Django и полностью упакованное в Docker. Проект предоставляет пользователям приватное пространство для создания, хранения и управления своими мыслями и воспоминаниями. Основной упор сделан на надежность, безопасность данных и простоту использования.

## 🚀 Ключевые возможности

- **Безопасная аутентификация:** Система регистрации и входа, гарантирующая, что доступ к записям есть только у их автора.
- **Полный CRUD:** Удобный интерфейс для создания, просмотра, редактирования и удаления записей.
- **Простой поиск:** Быстрый поиск по заголовку и содержимому записей.
- **Пагинация:** Удобная навигация по большому количеству записей.
- **Чистый интерфейс:** Адаптивный дизайн на основе Bootstrap5.
- **Контейнеризация:** Весь проект, включая базу данных PostgreSQL, запускается одной командой с помощью Docker Compose, что обеспечивает идеальную переносимость и простоту развертывания.

## 🛠️ Технологический стек

- **Бэкенд:** Python, Django
- **База данных:** PostgreSQL
- **Управление зависимостями:** Poetry
- **Контейнеризация:** Docker, Docker Compose
- **Фронтенд:** HTML, Bootstrap 5

## ⚙️ Установка и запуск (с помощью Docker)

Это **рекомендуемый** способ запуска проекта.

1. **Клонируйте репозиторий:**
   ```sh
   git clone <URL вашего репозитория>
   cd personal_diary
   ```

2. **Создайте файл окружения:**
   Скопируйте `.env.example` в `.env` и заполните его вашими данными. **Эти же данные используются в `docker-compose.yml`**.
   ```sh
   # .env
   SECRET_KEY='ваш_секретный_ключ_django'
   DEBUG=True

   POSTGRES_DB=personal_diary_db
   POSTGRES_USER=user
   POSTGRES_PASSWORD=password
   DB_HOST=db
   DB_PORT=5432
   ```

3. **Запустите Docker Compose:**
   Эта команда соберет образ, создаст контейнеры и запустит их в фоновом режиме.
   ```sh
   docker-compose up --build -d
   ```

4. **Примените миграции:**
   Создайте таблицы в базе данных.
   ```sh
   docker-compose exec web python manage.py migrate
   ```

5. **(Опционально) Заполните базу демонстрационными данными:**
   Эта команда создаст суперпользователя (`test` / `test`) и несколько записей для демонстрации.
   ```sh
   docker-compose exec web python manage.py seed_demo
   ```
   Если вы не использовали эту команду, создайте суперпользователя вручную:
   ```sh
   docker-compose exec web python manage.py createsuperuser
   ```

6. **Готово!**
   Откройте `http://127.0.0.1:8000/` в вашем браузере.
